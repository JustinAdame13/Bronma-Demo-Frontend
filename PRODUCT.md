# BRONMA

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Plataforma profesional de gestión de cobranza inteligente. El mapa permite localizar clientes, identificar cuentas que requieren atención y consultar su expediente.

## Capabilities and Constraints

React + TypeScript + Vite. Mapa Leaflet/OpenStreetMap, rutas, búsqueda, filtros de estado, selección de clientes, registro de pagos y captura de ubicación existentes. El sistema visual se comparte entre Mapa de clientes, Cartera, Recordatorios, Importar, Configuración y BRONMIA. El usuario amplió explícitamente el alcance para corregir la inconsistencia entre pantallas. Se conservan servicios, reglas, cálculos, rutas, persistencia y fuentes de datos.

## Brand Commitments

BRONMA; asistente BRONMIA. Logo existente en public/brand. Dorado, carbón, blanco y neutros. Calidad y sobriedad de producto profesional, con Linear y Stripe Dashboard como referencias de oficio, sin copiar su interfaz. Sin encabezados publicitarios, etiqueta demo ni «Operación Torreón».

## Operating Context

Uso principal confirmado por el usuario: oficina, para supervisar y priorizar la cartera. La consulta también debe funcionar en tablet y móvil.

## Accessibility & Inclusion

Contraste legible, navegación por teclado, estados de interacción claros y composición responsive.
